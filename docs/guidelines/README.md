# Project Guidelines

This directory contains operating rules for FraudShield Transactional.

These documents guide implementation, validation, review, and future evolution:

- `backend-best-practices.md`
- `git-workflow-rules.md`
- `observability-rules.md`
- `monitoring-rules.md`
- `security-rules.md`

Agents should read these guidelines when a task touches architecture, logging, monitoring, auditability, API behavior, persistence, or security-sensitive data.
